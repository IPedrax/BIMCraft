The broader local command excludes the desktop and UI packages:

```sh
cargo test --locked --workspace precision_ -- --skip precision_screenshots
cargo test --locked --workspace --exclude bimcraft --exclude bimcraft-ui-egui
```

The latter is a workspace subset, not a full local workspace pass. The CLI integration tests launch the CLI/DWG child only. Core subprocess tests launch their own test executable. Updater tests use temporary shell stand-ins for macOS launch/install tools; PyAddins editor tests use `true`, `false`, a missing executable, and a temporary sleeping shell script. These paths were inspected before execution. Local processes were audited; no native app was launched for this refresh.
