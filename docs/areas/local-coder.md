# Локальный помощник и взаимное ревью

Основной агент использует Qwen через `http://127.0.0.1:47831/v1`.
Перед обращением проверяет `/models`: нужен доступный `coder-iq1_m`.
Ошибка подключения внутри sandbox не доказывает недоступность сервера.
Повторить тот же read-only запрос через `exec_command` с
`sandbox_permissions: require_escalated`; не перезапускать Strata по одной
ошибке из sandbox. Только подтверждённая недоступность переводит работу на основной агент.

Рабочая точка входа — MCP `mcp__qwen__delegate_qwen`: найти `qwen` в `ALL_TOOLS`.
Регистрация находится в `.codex/config.toml`, сервер — `scripts/qwen_mcp.py`.
Наличие MCP-инструмента и доступность модели — отдельные проверки.
Резервный ручной вход — `python scripts/delegate_qwen.py`; задание хранится в
`.memory/01_BLACKBOARD.md`. Общая память, протокол диапазонов и автоматический
цикл `cargo check` описаны в [регламенте памяти](shared-memory.md).
Прямые HTTP-вызовы ниже нужны для диагностики; рутинные задания идут через
единый исполнитель. Он использует low reasoning для правок и medium для ревью.

## Проверка связи

Найти `qwen` в `ALL_TOOLS`: рабочий инструмент — `mcp__qwen__delegate_qwen` (конфигурация `.codex/config.toml`, сервер `scripts/qwen_mcp.py`). Перед обращением проверить `curl.exe --noproxy 127.0.0.1 --fail -sS --connect-timeout 3 --max-time 10 http://127.0.0.1:47831/v1/models`: нужен HTTP-успех и `coder-iq1_m`. Ошибка localhost внутри sandbox не доказывает недоступность: повторить проверку с `sandbox_permissions: require_escalated`. Только подтверждённая недоступность переводит работу на основной агент. Задания идут через MCP и доску; HTTP `/v1/chat/completions` с `model: coder-iq1_m` — для диагностики.

## Проверенная конфигурация

Установлена **Qwen3.8-Flash-Next Coder IQ1_M**: backend HIP, контекст 131072
токена, KV int8. Пустое поле `gpus` в `/models` не означает работу только на CPU.
Версия весов по одному имени модели не подтверждается.

Карточка Coder описывает удаление половины экспертов и точность оставшихся
весов 3,5 бита. IQ1_M не означает, что все веса однобитные. Для обновления
от 17 октября авторы сообщают SWE-bench Verified 79,20% и LiveCodeBench v6
87,43% при xhigh reasoning. Это результаты авторов, не замеры нашего экземпляра.
[Источник и ограничения](https://huggingface.co/ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-Coder-GGUF).

## Распределение работы

- Локальная модель: механические правки, бойлерплейт, поведенческие тесты,
  ограниченные исправления ошибок, локальный рефакторинг и независимое ревью.
  Расширять задачи после успешной проверки похожей работы.
- Основной агент: архитектура, межмодульные контракты, сложная логика Rust,
  интерпретация норм, риски потери данных и итоговая валидация.
- Передавать точные файлы или фрагменты, реальные API, ограничения,
  ожидаемое поведение и команду проверки. Модель не видит репозиторий сама.
  Не поручать разным исполнителям одновременно изменение одного файла.

## Взаимная проверка

Основной агент читает каждый diff, отклоняет выдуманные API, воспроизводит
ошибки тестами и запускает проверки. Ответ помощника не заменяет компиляцию,
тесты и clippy. После собственного законченного изменения основной агент
передаёт помощнику код и тесты для независимого ревью. Нужны конкретный
сценарий ошибки и строка. Каждую находку основной агент проверяет сам;
отсутствие находок не доказывает корректность.

Проверять `finish_reason`: обрезанный ответ не считается законченным.
Бюджет ответа должен позволять закончить задачу. Первый обрезанный тестовый
черновик был отклонён из-за выдуманных API; точные сигнатуры улучшили ответ.

## Нагрузка

Один локальный запрос за раз. Перед генерацией проверять САПР и интерактивную
3D-нагрузку. При работающей САПР требуется подтверждённый режим Strata
**Leave 20% for my work**; иначе генерацию отложить. Один запрос или фиксированный
резерв VRAM этот режим не заменяют. Без интерактивной нагрузки допустим
Full performance. Сборки и тесты ограничивать по параллелизму; между длинными
сериями делать паузы.

Если пользователь явно подтвердил режим Leave 20%, Codex записывает в конкретное
задание доски `strata_reserve: "leave_20_percent_confirmed_by_user"`.
Обёртка учитывает это подтверждение до запроса и после ответа, сохраняя один
локальный запрос. Без поля открытая САПР блокирует генерацию; ошибка определения
процессов блокирует её даже при подтверждении. Поле не включает режим Strata
автоматически: его записывают только после подтверждения пользователя.
