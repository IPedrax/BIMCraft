# Шаблоны выпуска ПД

Исходная папка пользователя: `E:\Работа\0_Шаблон Libre`.
Структура архивов ODF проверена 01.11.2026 без изменения исходников.
Экспорт по этим шаблонам ещё не реализован; это входные данные этапа 8
[плана СПС/СОУЭ](../low-voltage-roadmap.md).

| Файл | Проверенное назначение или связь |
| --- | --- |
| `0 Титул А4.odt` | Титул, связанный раздел из `Info.odt` |
| `1 СТ.odt` | Содержание тома, связанный раздел из `Info.odt` |
| `2 СП.odt` | Состав проектной документации, связанный раздел из `Info.odt` |
| `3 ТЧ.odt` | Текстовая часть, связанный раздел из `Info.odt` |
| `Info.odt` | Общие реквизиты и разделы `MasterShtamp`, `MasterShtampML` |
| `СО.odt` | Отдельный документ со связанным разделом из `Info.odt`, присутствуют стили страниц А3 альбомной ориентации |
| `Текстовая часть.odm` | Составной документ: титул, содержание, состав ПД, текстовая часть; `СО.odt` в список его связанных разделов не входит |
| `Текстовая часть.pdf` | Готовый PDF в исходной папке; в этой проверке страницы не просматривались |
| `Шаблон для ПД.ott` | Шаблон Writer со стилями и встроенными изображениями |

В `Info.odt` используются `text:variable-set` и `text:variable-get`, а не только
пользовательские поля `text:user-field-*`. Объявлены, в частности, `Addres`, `Data`,
`Firma`, `NameOb`, `NameZakazchik`, `Shifr`, `ShifrSP`, `TitleFamilie1`,
`TitleFamilie2`, `LPage`, `Имя_раздела`, `Раздел`, `Суффикс`.
Текстовая часть дополнительно использует переменные страниц `StartPage`, `EndPage`,
`Page` и `КонецТЧ`. Назначение каждой переменной нужно сопоставить с печатным
результатом перед заполнением; одних имён для надёжной подстановки недостаточно.

При реализации сохранять стили, изображения, относительные ссылки на документы
и ручные абзацы. Изменять только явно сопоставленные реквизиты и генерируемые
области. Сборка копии комплекта должна сохранять работоспособность связанных
разделов после переноса в папку проекта. Вычисление полей и окончательную пагинацию
проверять на отрендеренном PDF; чтение XML не подтверждает качество оформления.

ODS-шаблона печатной спецификации в этой папке нет. `СО.odt` нельзя считать
готовым шаблоном листов 2+ каталога ODS. Согласованное требование о базе на первом
листе ODS сохраняется; перенос оформления спецификации требует отдельной проверки.
Пользовательские документы и изображения не включались в поставку BIMCraft.
