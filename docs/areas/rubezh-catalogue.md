базы-изолятора ИЗ-1Б-R3 руководство указывает два адреса на комплект.
Потребление самого извещателя в дежурном режиме ограничено 0,32 мА при 28–36 В;
потребление изолятора учитывается отдельно (РЭ, пункты 2.4, 2.6–2.7).

Для расчёта массы демонтажа паспортное «не более» следует показывать как
оценку сверху. Текущая структура Product хранит только число; происхождение и
тип ограничения ещё нужно включить в модуль каталога. При включённом основании
не добавлять такое же основание второй раз автоматической комплектацией.
