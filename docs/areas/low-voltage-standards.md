# Источники российского нормативного пакета СПС/СОУЭ

Проверено 01.11.2026 по официальному фонду Росстандарта. Это журнал версий
для этапов 6–7 [плана](../low-voltage.md), а не реализованный пакет
проверок. Карточка документа подтверждает редакцию и даты; условия расчёта
нужно отдельно сверять с полным текстом и всеми применимыми изменениями.

Редакцию 2009 года нельзя молча использовать для нового пакета СОУЭ.
Применимость конкретному проекту должна сохраняться вместе с выбранной версией
пакета; обновление пакета не меняет уже утверждённые расчёты без команды пользователя.
Иностранные пакеты остаются вне текущего выпуска.

## Перед превращением текста в правило

- Для каждой исполняемой проверки записать документ, редакцию, пункт,
  необходимые входные параметры и контрольный пример. Статус «данных недостаточно»
  отличается от соблюдения требования.
- Полные тексты изменений и поправки ещё нужно сопоставить с основными текстами.
  Наличие карточки в фонде не означает, что числовые условия уже перенесены в код.
- Наименование помещения помогает определить назначение, но само по себе
  не описывает условия запотолочного или подпольного пространства. Проверять
  их отдельно при автоматическом пересмотре защиты после обновления IFC.
- Автоматическая расстановка, удаление и установка изоляторов должны проверяться
  по закреплённой редакции. Геометрический скрипт Renga не является источником норм.
- Нагрузки, собственное потребление и ограничения оборудования брать из
  [журнала производителя](rubezh-catalogue.md); противоречия карточек и паспортов
  не заменять неподтверждённым значением.

Официальное [уведомление МЧС об изменении СП 484](https://61.mchs.gov.ru/uploads/resource/2025-08-14/informirovanie-o-soblyudenii-obyazatelnyh-trebovaniy-pozharnoy-bezopasnosti_1755175156761234994.pdf)
указывает, в частности, на изменения требований к ЗКПС и последствиям единичной
неисправности линии. Уведомление используется для поиска изменённых мест;
пороговые значения и исключения нужно брать из полного нормативного текста.
