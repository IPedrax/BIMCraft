# Горячие клавиши

Два вида привязок живут рядом:

- **Последовательности из двух символов**, как в Revit (`WA`, `DR`, `KF`). Их список — `SHORTCUTS` в `lib.rs`; свои
  добавляет, меняет и загружает Manage > Shortcuts (`shortcuts_window` в `shortcuts.rs`). Пользовательские привязки
  лежат в `settings.json` (поле `shortcuts`: ключ — два символа, значение — английское имя действия) и читаются в
  `BimApp::custom_shortcuts` при старте (`use_settings`). Назначать модификаторные комбинации (`Ctrl+…`, `F…`) этот
  диалог пока не умеет: это появится вместе с ТЗ-008.
- **Жёстко зашитые комбинации** для частых команд окна: файл, отмена, поиск, стартовая страница, направляющие
  выравнивания. Они проверяются в `BimApp::keys` (`lib.rs`) и не настраиваются.

## Изменения ТЗ-009

ТЗ-009 освободило две комбинации и оставило одну функциональную клавишу для направляющих.

| Действие | Было | Стало |
|---|---|---|
| Home / стартовая страница | `Ctrl+D` | `Ctrl+U` (`⌘U` на macOS) |
| `Ctrl+D` | Home | свободна; своего действия по умолчанию нет |
| Направляющие выравнивания | `F8` и `F11` | только `F8` |
| `F11` | направляющие | свободна; её может забрать ОС для полноэкранного режима |
| `Ctrl+U` в редакторе заметок | Underline | Underline (без изменений) |
| `Ctrl+Г` на ЙЦУКЕН | — | Home: `egui` присылает физическую клавишу `U` |

Почему так: Home — редкое действие, ему достаточно `Ctrl+U`, а удобная для одной руки `Ctrl+D` освобождается под
пользовательские команды. `F11` часто занята оконным менеджером, поэтому приложение больше её не потребляет.

## Приоритет контекста

- Модальный диалог забирает клавиши первым: внутри него `Ctrl+U` и `F8` не глобальные.
- В текстовом поле клавиши принадлежат полю: `Ctrl+U` не открывает Home.
- При редактировании заметки с Override Formatting `Ctrl+U` остаётся подчёркиванием (`notes.rs`), Home не открывается.
- На обычном холсте `Ctrl+U` открывает стартовую страницу, `Ctrl+D` ничего не делает по умолчанию, `F8`
  включает и выключает направляющие.
- `AG` и `OG` — legacy-последовательности Revit-стиля; они по-прежнему переключают направляющие. Критерий «только
  `F8`» относится к функциональным клавишам.

## Подсказки и переводы

Подсказка кнопки Home на панели быстрого доступа — `Home (Ctrl+U)` (`Home (⌘U)` на macOS), кнопки Back на стартовой
странице — `Back to the project (Ctrl+U)`. Обе строки собираются через `tf`, шаблоны лежат в
`translations/ui/bimcraft-ui.pot`. Текст подсказки Home показывает `Ctrl+U`, потому что на ЙЦУКЕН физическая `U`
подписана `Г`: пользователю с русской раскладкой нужно нажать `Ctrl+Г`.
