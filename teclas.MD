**Gerais**

**3D** – Vista 3D / Abrir representação 3D padrão

**UN** – Unidades de projeto

**Esc** – Encerrar uma ação/ Sair de um comando/ Limpar as cotas temporárias

**SU** – Configuração do Sol

**DI** - Cria uma dimensão alinhada.

**DL** - Cria linhas específicas da vista.

**TG** - Aplica identificadores aos elementos com base em suas categorias

**UE** - Ativa um elemento oculto para que apareça na vista.

**PP ou CTRL-1 ou VP** - Alterna a paleta Propriedades.

**LL** - Coloca um nível na vista.

**LI** - Coloca uma nova linha.

**CM** - Insira um componente.

**AL** - Alinha um ou mais elementos a um elemento selecionado.

**PN** - Bloqueia um elemento do modelo no lugar.

**SL** - Corta um elemento (como uma parede ou linha) em um ponto selecionado.

**KS** - Atribui sequências de teclas para ferramentas.

**NP** - Navegador de Projetos

**CR** - Corte

**TL** - Exibe todas as linhas na tela com uma largura única, independentemente do nível de zoom.

**HH** - Esconde aquele objeto ou identificação (Oculta um elemento da vista).

**HC** - Esconde todos os objetos daquela categoria (Oculta todas as categorias selecionadas na vista).

**TAB** - Apertar Tab seleciona toda a extensão do elemento, no caso, alterna as partes para selecionar o elemento desejado na vista.

**Barra de Espaço** - Rotaciona os elementos selecionados.

**HR** - Restaura quaisquer elementos ou categorias ocultos temporariamente.

**Operações em arquivos**

**Ctrl + O** – Abrir novo arquivo

**Ctrl + N** – Criar novo arquivo de projeto

**Ctrl + S** – Salvar arquivo

**Ctrl + P** – Imprimir

**Ctrl + Z** – Desfazer

**Ctrl + Y** – Refazer

**Ctrl + C** – Copiar para área de transferência

**Ctrl + V** – Colar

**F1** – Ajuda

**Seleção de objetos**

**Ctrl** – Selecionar vários elementos

**Shift** – Remover da seleção

**Tab** – Alternar a seleção de objetos próximos

**SA** – Selecionar todas as instâncias

**Arquitetura**

**WA** – Criar parede

**SB** – Criar piso

**DR** – Inserir porta

**WN** – Inserir janela

**CM** – Inserir componente

**SF** – Dividir face

**LL** – Colocar um nível na vista

**CL** – Adicionar pilar estrutural

**LI** – Linha do modelo

**MA** – Igualar propriedades

**CS** – Criar um elemento novo similar

**DL** – Criar linhas de detalhamento

**RM** – Criar ambiente delimitado por paredes ou linhas de separação

**Estrutural**

**BM** - Adiciona um elemento de viga estrutural de suporte de carga ao modelo de construção.

**BR** - Adiciona membros diagonais que estão conectados a vigas e colunas.

**BS** - Cria um layout que é utilizado para controlar o número e o espaçamento de uma série de vigas paralelas.

**CL** - Adiciona um elemento de suporte de carga vertical no modelo de construção..

**FT** - Cria uma fundação de parede para o modelo de construção.

**GR** - Coloca linhas de eixo de coluna no projeto de construção.

**RN** - Define ou edita as sequências de numeração por partição para vergalhão e folhas de tela soldada.

**RP** - Cria um plano de referência utilizando ferramentas de desenho.

**Elétrica**

**CN** - Desenha um condutor de conduíte rígido (Atalho para a Ferramenta Conduítes).

**CT** - Desenha um condutor de bandeja de cabos.

**CV** - Converte uma seção de duto rígido em duto flexível.

**EE** - Coloca equipamento elétrico, como painéis e equipamentos alternativos.

**TF** - Coloca acessórios da bandeja de cabos.

**EW** - Desenha um trecho de fio em arco.

**DA** - Adiciona acessórios de duto, como abafadores, em sistemas de duto.
